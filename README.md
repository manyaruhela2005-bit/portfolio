# Profile Animation Demo

This is a minimal static demo showing:

- a fixed (non-scrolling) stage with continuously running frame animation
- a greeting text that enters letter-by-letter from left to right and stops around the center while avoiding overlap with the girl image

How to use:

1. Open `index.html` in your browser (double-click or use a local static server).
2. Replace the placeholder SVGs in `frames/` with your own frames (keep the same filenames or update `script.js`).

Files:

- index.html: demo page
- styles.css: styling and layout
- script.js: frame cycling + greeting animation logic
- frames/: placeholder SVG frames
