Project Overview

Developed for the Smart India Hackathon (SIH) under Team "BOT DRAGONS", this project transforms traditional CCTV infrastructure into an intelligent surveillance platform. It is designed for perimeter and restricted-area security where continuous manual CCTV monitoring is inefficient and security personnel need immediate awareness of important events.

The Problem

Traditional CCTV systems primarily record video and depend heavily on human operators. Key problems include:

  • Continuous manual monitoring is exhausting and error-prone.
  • Important incidents can be missed or suspicious activity detected too late.
  • Monitoring multiple cameras rapidly increases operator workload.
  • Traditional CCTV does not automatically understand events.
  • Night-time conditions severely degrade manual monitoring.
  • Collecting incident evidence manually consumes critical time.

The Solution

  • Adds an AI intelligence layer to existing CCTV infrastructure
  • Automatically analyzes live video feeds
  • Understands spatial events and activities
  • Detects and highlights important security incidents
  • Reduces the need for continuous manual monitoring
  • Provides real-time security alerts

Key Surveillance Features

Human Detection & Tracking

Detects people entering monitored areas and tracks their movement continuously across the camera feed using YOLOv8 and ByteTrack.

Face Recognition

Detects and recognizes faces dynamically to support watchlist-based security alerts for known, unknown, or blacklisted individuals.

ANPR & Vehicles

Automatically detects vehicles, classifies them, and reads license plates for comprehensive access control.

Virtual Fence & Zones

Allows operators to create polygon-based restricted zones directly on the video feed to instantly detect unauthorized entry or loitering.

Suspicious Activity

Intelligently flags intrusion, loitering, crowd formation, tailgating, wrong direction movement, and objects left behind.

Real-Time Alerts & Evidence

Generates immediate alerts via In-app, WebSocket, Email, or Webhooks, complete with screenshots, timestamps, and severity levels.

The system employs a multi-stage AI layer. YOLOv8 processes object detection, which feeds into ByteTrack/SORT for temporal persistence. This data intersects with spatial polygons in the Rule Engine to flag breaches, while Redis handles real-time alert broadcasts to the Next.js frontend.

Alerts, Security Rules & Administration

Event Lifecycle: Intrusion

1. Person enters restricted zone
2. YOLOv8 detects person
3. Tracking identifies movement vector
4. Virtual fence rule is triggered
5. Severity assigned (e.g. Critical)
6. Alert generated
7. Screenshot + timestamp stored in DB
8. Operator receives real-time alert UI pop-up

Alerts are assigned one of five severity levels (Critical, High, Medium, Low, Info) and include configurable cooldowns to prevent alarm fatigue.

Security Rules & Management

The system supports 22 configurable detection rules encompassing:

  • Security: Intrusion, Loitering, Tailgating, Objects left/removed.
  • Counting & Occupancy: Line crossing, threshold breaches.
  • Face & Vehicle: Blacklisted detection, Speed, Illegal parking.
  • Safety: PPE violations, Fire/smoke, Fall detection.

Administrators maintain full control via Role-Based Access (Viewer to Super Admin), allowing dynamic zone configuration, API key management, and comprehensive PDF/CSV audit reports. An advanced natural-language AI Copilot (powered by Claude) provides contextual querying of this surveillance data.

Technology & Challenges

Technology Stack

  • Computer Vision: Python, YOLOv8, OpenCV, RetinaFace, ArcFace, PaddleOCR, ByteTrack.
  • Frontend: Next.js, React, TypeScript, Tailwind CSS, Zustand, HLS.js.
  • Backend: FastAPI, Python, WebSockets.
  • Infrastructure: PostgreSQL, Redis, MinIO, MediaMTX, Docker.

Challenges

Engineering Challenges:

  • Processing multiple video streams concurrently while maintaining real-time inference.
  • Tracking objects persistently across frames and varying lighting conditions.
  • Integrating heavy AI inference with live low-latency video streaming.
  • Managing camera connectivity and MediaMTX health.
