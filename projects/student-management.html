Project Overview

The NGO Student Management System is a student-focused management platform that centralizes student information and academic performance tracking. It allows authorized users to manage student records, attendance, notes, grades, and performance information through two interfaces — a Flask-based web application and a Tkinter-based desktop application — both connected to a shared MySQL database.

The Real-World Problem

Manual student tracking creates real organizational challenges:

  • Difficult to maintain organized student records
  • Inconsistent attendance tracking
  • No centralized place to record test results
  • Notes and academic progress scattered across files
  • No easy way to compare student performance
  • Monitoring progress over time becomes error-prone
  • Retrieving information efficiently is tedious

The Solution

The system provides a centralized platform where student information and academic records can be stored and managed:

  • Centralized student records in a structured database
  • Organized attendance tracking per student
  • Structured grade and test result storage
  • Notes maintained alongside student profiles
  • Performance tracking using marks and averages
  • Secure, authenticated access for authorized users

Key Features

Student Records

Store and manage comprehensive student information including name, age, school status, academic information, test results, and reports.

Attendance Management

Record and manage student attendance in a structured, consistent, and retrievable manner for each student profile.

Grades & Test Results

Store individual student test marks and academic results, enabling structured tracking of academic progress over time.

Notes & Observations

Maintain notes related to individual students and their academic progress, linked directly to their profile.

Performance Tracking

Track academic performance using marks, averages, and evaluations to monitor each student's growth over time.

Authentication

Secure login functionality using Flask-Login and Werkzeug password hashing to ensure only authorized users can access the system.

Database Design

The system uses MySQL (database: ngo) as a relational database. Student information, attendance, notes, grades, and user authentication are separated into structured, interrelated tables.

students

Core student profiles and personal information

attendance

Per-student attendance records linked by ID

notes

Academic and progress notes per student

grades

Test marks and academic results per student

users

Authorized user accounts with hashed passwords

Built from Real Student-Management Needs

This system was directly informed by hands-on interaction with students at an NGO/orphanage. The activities carried out during this engagement included:

Academic Support

  • Literacy and syllabus support
  • Doubt-clearing sessions
  • Weekly tests and assessments
  • Performance evaluation

Student Activities

  • Creative activities
  • Extracurricular activities
  • Direct student interaction
  • Student needs identification

System Motivation

These direct interactions helped identify the genuine need for structured academic tracking — records, attendance, grades, and notes were being managed manually, making it harder to monitor student growth consistently. The system was built to address these real organizational challenges.
